# AI Stack Map

- `ai-stack-map-LATEST.html` — ultima versiune completă (o deschizi pe telefon / calculator).
- `ai-stack-map-mobile-N.html` — fiecare actualizare, păstrată separat.
- `update_stack_map.py` — actualizează prețul, %, market cap, volum, P/E și earnings pentru toți tickerii (sursa: Yahoo Finance).
- `.github/workflows/update.yml` — rulează scriptul automat luni–vineri după închiderea bursei; din tab-ul **Actions → Update AI Stack Map → Run workflow** îl pornești manual oricând.
- `update-log.txt` — ce s-a schimbat la earnings la fiecare rulare.
